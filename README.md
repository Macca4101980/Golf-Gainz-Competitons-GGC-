# Golf Gainz Comps — Build 3.4 Individual Formats

Build 3.4 adds the first competition-format category: Individual.

Formats: Stableford, Nett Stroke Play / Medal, Gross Stroke Play, Par / Bogey, Maximum Score and Singles Match Play.

Handicap allowance defaults follow the R&A/WHS Appendix C recommendations used by this build: 95% for individual handicap stroke-play formats, 100% for Singles Match Play and 0% for Gross Stroke. The competition creator can override the allowance where applicable. Plus handicaps are supported.

Settings → Regression Testing → LOAD INDIVIDUAL FORMATS TEST PACK loads the deterministic test competitions from `test-data.json`.

See `GGC-3.4-EXPECTED-RESULTS.json` and `GGC-MASTER-REGRESSION-AUDIT.md`.
