# Build 3.8R2 — verified formats only
Normal Create Competition menu now exposes only the five currently implemented scoring formats:
- Individual Stableford
- Stroke Play / Medal
- Gross Stroke Play
- Par / Bogey
- Blind Pairs

All other Build 3.8R1 behaviour is retained, including OOM hotfix, 9-hole selection, editable Handicap Index, handicap snapshots, PWA/mobile fixes and test pack.
The underlying scoring rules remain in source for future development; unsupported formats are simply hidden from normal competition creation.
